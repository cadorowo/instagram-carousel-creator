# Style Guide — Brutalist Bold (High Impact / Streetwear / GenZ)

## Identità Visiva
Stile ad altissimo contrasto, impatto visivo netto, tipografia bold a caratteri cubitali, bordi decisi, sticker tags ed estetica contemporanea.

## Palette Colori
- **Sfondo:** Off-White / Gesso `#F3F3F3` (o Nero Assoluto `#0C0C0C` per dark mode)
- **Testo Primario:** Deep Black `#0A0A0A`
- **Accento Primario / Sticker:** Giallo Elettrico `#E8FE46` (oppure Blu Cobalto `#0047FF` / Rosso Acid `#FF2A2A`)
- **Bordi & Box:** Solidi `#0A0A0A` (spessore 3px - 5px)

## Tipografia
- **Titoli:** `Syne` (800) / `Clash Display` / `Plus Jakarta Sans` (800) in Uppercase con tracking stretto (`letter-spacing: -2px`)
- **Corpo:** `Space Mono` / `JetBrains Mono` / `Inter` (500, 700)

## Componenti Chiave
- Badge sagomati e sticker rettangolari con angoli a 0px o pillola estrema
- Riquadri fotografici con ombra dura sfalsata (`box-shadow: 8px 8px 0px #0A0A0A`)
- Trattamento testo bold evidenziato con sfondi contrastanti
