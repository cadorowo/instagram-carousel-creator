# Brand Style Config

Questo file viene letto dall'agente prima di ogni fase. Modifica i valori qui sotto:
sono le uniche fonti di verità per colori, font e tono — non hardcodare colori diversi
nei template o nei testi.

## Palette colori
- Colore base (sfondo): `#0F0F0F`
- Colore accent: `#FF5A36`
- Colore testo primario: `#FFFFFF`
- Colore testo secondario: `#B3B3B3`

## Font
- Titoli: `Inter`, peso 800 (Extra Bold)
- Corpo: `Inter`, peso 400 (Regular)
- Numeri/statistiche in evidenza: `Inter`, peso 900 (Black)

## Tono di voce
- Diretto, informale ma competente.
- Frasi corte, massimo una idea per frase.
- Nessun linguaggio da "corporate stock", niente superlativi vuoti ("il migliore",
  "incredibile") senza dato a supporto.

## Formato e limiti
- Numero slide per carosello: 6-10 (ideale 8).
- Formato: 1080x1350px (4:5).
- Testo titolo: massimo 8 parole.
- Testo corpo per slide: massimo 25 parole.
- Ultima slide sempre CTA (una sola azione richiesta, non multiple).

## Logo/watermark
- Percorso logo: `brand/assets/logo.svg` (aggiungi il tuo file qui)
- Posizione di default: angolo in basso a destra, 48px di margine, opacità 80%.
